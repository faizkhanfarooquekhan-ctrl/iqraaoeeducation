# IQRA AOE · Academy of Excellence

Premium dark-mode classroom for English, Hindi, Urdu, and Maharashtra State Board mathematics (Classes 1–10).

## Install

```bash
npm install
```

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
